		\section{Metodologia}
		
			% ALTERAR O TEXTO
			É feito o desenvolvimento da matemática denominada K-means como possível ferramenta para a classificação (taxonomia) das aeronaves. Em seguida, será feita a aquisição dos dados (variáveis das principais características das emissões dos motores de aeronaves) a partir da European Union Aviation Safety Agency (EASA) para gerar o banco de dados, logo, será feita a implementação computacional na qual, a linguagem de programação escolhida inicialmente é o Python \cite{Kiusalaas2010}. Assim, poderá ser feita a análise e validação dos grupos separados pelo modelo, o que permitirá determinar qual rumo o projeto deverá seguir dependendo do projeto.
