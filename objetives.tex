		\section{Objetivo da Pesquisa}
		
			\subsection{Objetivo Geral}
			
				O objetivo geral é obter diretrizes para novos desenvolvimentos a partir dos resultados obtidos, tendo em vista que, a solução irá direcionar um projeto em termos das suas características físicas (pressão, temperaturas, vazões etc.)e geométricas (dimensões), tendo em vista que poderá explicitar, baseado nos projetos já desenvolvidos, onde é que está a solução ou inovação daquele projeto para direcionar o projeto no qual está sendo trabalho. A ideia é que a matemática utilizada indique que um determinado projeto possui uma solução válida para novos desenvolvimentos.
				
				Sendo assim, um novo projeto poderá ser retroalimentado - antes e durante o seu desenvolvimento - na metodologia desta Proposta Inicial de Pesquisa para medir o rumo no qual o projeto está tomando. Em outras palavras, será possível medir se o projeto está atendendo os requisitos iniciais, até mesmo ajustar esses requisitos para que se obtenha um projeto de melhor custo-benefício, sobretudo, um projeto de sucesso em termos gerais já que, com os resultados, as variáveis de projetos, novamente, serão direcionadas e repensadas abtraindo detalhes de extrema expecificidade.
			
			\subsection{Objetivos Específicos}
			
				Com o uso da Inteligência Artificial(AI) \cite{Russell2002} aplicada, a solução da pesquisa trará uma melhor compreensão sobre as motores de aeronaves já desenvolvidos a partir das suas emissões, isso, ajudará no desenvolvimento de novos projetos de motores, pois explicita o que porque as motores de aeronaves deram certo no que se refere a projeto, mercado de vendas etc.. Contudo, poderá ser verificado qual o projeto de motor de melhor custo-benefício, não somente economicamente, mas também no que diz respeito a engenharia (tempo de projeto, eficiência e eficácia).
